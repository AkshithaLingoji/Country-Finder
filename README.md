🌍 Country Finder

Country Finder is a simple web application that allows users to search for any country and view detailed information using the REST Countries API.
This project was built as part of my JavaScript learning journey, with a focus on understanding API calls, asynchronous programming, and dynamic UI updates.

✨ Features

- Search countries by name
- Fetches real-time data from the REST Countries API
- Displays key information such as:
  - Capital
  - Population
  - Area
  - Region and Subregion
  - Languages and Currencies
  - Timezones and Borders
  - Country Flag and Coat of Arms
- Handles invalid or misspelled country names gracefully
- Clean UI state handling (searching, success, no results)



🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- REST Countries API


🎯 Learning Outcomes

Through this project, I learned:
- How to fetch data from an external API using `fetch`
- How to work with `async` / `await`
- How to structure JavaScript code using functions
- How to update the UI dynamically based on API responses
- How to handle loading and error states in a user-friendly way.
